## 1. 研究主线（一图说清）

```
                         ┌─────────────────────────────────────────────┐
                         │  问题：戴 VR 头显 → 上半脸被遮挡              │
                         │  目标：仍能实时识别 7 类情绪                  │
                         └─────────────────────────────────────────────┘
                                            │
        ┌───────────────────────────┬───────┴───────────────┬─────────────────────────┐
        ▼                           ▼                       ▼                         ▼
  (数据来源1) 合成数据        (数据来源2) 真实采集       (诱导手段) 360刺激         (模型) 三条基线
  ComfyUI 生成戴VR人像      Quest Pro 多模态 session     VR刺激图面板+WebXR       ①图像式 ②混合形状式
  + VRMask 合成遮挡         (下半脸图像+70维FACS+标签)   诱发自然表情             ③融合/跨模态蒸馏
        │                           │                                                   │
        └──────────► 训练/评测：真实遮挡 vs 合成遮挡对照，单模态 vs 融合对照 ◄──────────┘
```

## 2. 三个数据阶段

1. **合成先行（已可用）**：ComfyUI「生成表情」批量产出戴 VR 人像 → 现有 `ImageFolder` 训练器 + `VRMask`。用于冷启动基线，不依赖真人。
2. **真实采集（任务书阶段）**：Quest Pro session 产出「下半脸图像 + 70 维 FACS + 情绪标签」。用于验证合成→真实的迁移差距。
3. **混合训练**：合成预训练 + 真实微调；评测集固定为**真实 VR 遮挡**。

## 3. 三条模型基线

| 基线 | 输入 | 复用/新增 | 说明 |
|---|---|---|---|
| ① 图像式 | 下半脸 RGB 224×224 | 复用 `backend/src/use_train`（efficientnet_b2 / vr_cnn）| 现有能力，需把采集图摊平成 ImageFolder（B3）|
| ② 混合形状式 | **70 维** FEA（OVRPlugin.FaceExpression2）| **已有雏形**：notebook 的 FEA 分支（MLP 70→128）| Quest Pro 独有信号，含被遮挡区 |
| ③ 融合 | 图像 + 70 维 FEA | **已有脚手架**：[../DataSet/train_multimodal_fer_vr.ipynb](../DataSet/train_multimodal_fer_vr.ipynb)（后期融合，dummy 可跑）| 验证 RQ3；对齐 EmoHeVRDB 可合并训练 |

- 数据格式沿用 [../DataSet/quest_pro_capture_spec.md](../DataSet/quest_pro_capture_spec.md)（70 维、224×224、按受试者划分）。
- 若要把 ②③ 接入实时推理层：让其 forward 适配 `model_registry` 的 `predict_emotions(rgb, logits) -> (label, scores)`（③ 还需一路 FEA 输入，接口需扩展，属后续项）。

## 4. 分阶段里程碑（对应任务书 M1–M5）
- **M1 刺激库**：筛出 7×20 精选全景（本周可做，纯软件）。
- **M2 采集工具链**：三路同步采集程序 + 落盘格式。
- **M3 试采集** → **M4 正式采集**（依赖真人 + 头显）。
- **M5 基线与对照**：图像/混合形状/融合，产出 RQ1–RQ4 结论。

## 6. 风险与对策
- **Quest Pro 无原始人脸图** → 图像模态必须靠外部相机（任务书 §1.2 已定）。
- **诱导 ≠ 真情绪** → 自评 + FACS 弱标签校验（任务书附）。
- **合成→真实域差** → 混合训练 + 真实集评测。
- **同源泄漏** → 按受试者划分。
