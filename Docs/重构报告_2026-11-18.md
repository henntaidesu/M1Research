## 4. 代码改动

### 后端（`CoreCode/backend`）
- `config.py`：`ROOT` 改为仓库根（`parents[3]`）。新增 `BACKEND_DIR`、`MY_DATASET_DIR`。路径改为：`DATASET_DIR → DataSet/PublicDataSet`，`CAPTURE_DIR`/`AFFECT_DATA_DIR`/`IMAGE_DIR → DataSet/MyDataSet/{Capture,AffectData,Stimulus}`，训练产出放到 `CoreCode/backend/`。删除 adb、Postgres、研究日志、检测后端白名单、在线预测窗口等配置项。
- `app.py`：删除第 3 节列出的路由。启动时不再加载 MTCNN/HSEmotion，只做 CUDA 设备选择，启动更快。
- `model_registry.py`：去掉「激活模型」逻辑，只保留列模型与加载自训模型（训练和评测都用）。内置 HSEmotion 仍可作为评测基线，评测时按需加载。
- `settings_store.py`：去掉 `postgres` 分组。
- `requirements.txt`：去掉 `psycopg`。
- **新增 `train_timeline.py`**：在自采数据集上训练时序模型的命令行入口（`--loso` 为留一受试者交叉验证）。原来只能在 Python 里 import 调用。

### 数据流水线（`DataSet/MyDataSet`）
- **新增 `export_affect_timeline.py`**（替代 `export_pg_timeline.py`）：把链路 A（头显 `/api/fea` → `AffectData/` CSV）的数据导成训练脚本能读的 `Capture/` 格式。迁移前链路 A 的 CSV 数据没有任何路径能进入训练，这是本次补上的缺口。
- `check_rule_parity.py`、`calibrate_classify_fea.py` 等脚本：import 路径和默认路径适配新结构；用法说明统一为在仓库根目录运行。

### 前端（`CoreCode/frontend`）
- 路由与侧栏：删除摄像头、关于、研究日志页；`/cn`、`/jp` 默认跳到「VR 刺激图」页。
- `AffectPreferencePanel.vue`：删除 2D 摄像头来源，情绪来源固定为 Quest Pro FEA。
- `SystemSettingsPanel.vue`：删除 Postgres 区块。
- `vite.config.js`：删除 `/ws` 代理。
- `locales/zh.js`、`ja.js`：删除已删页面的文案，以及更早就没人引用的 ComfyUI/检测相关键（各从约 600 行减到 256 行）。

### Unity
没有修改。确认 Unity 调用的接口全部保留：`/api/fea`、`/api/session/*`、`/api/affect/selfreport`、`/api/stimulus/*`、`/api/headset/rtc/*`。
